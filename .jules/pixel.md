## 2024-09-06 - [Brutalist Shadow Math]
**Learning:** [When defining a base brutalist shadow (like shadow-brutalist-red), its pixel offsets must exactly match the button's active translate values (e.g., active:translate-x-1 = 4px). Otherwise, the shadow won't fully visually "erase" when the user clicks the button.]
**Action:** [Always verify that the base shadow token aligns with the component's active and hover translation mathematics.]

## 2024-05-24 - Brutalist Loading Spinners
**Learning:** The established pattern for brutalist loading spinners in this app uses a square spinner element (`<div className="h-4 w-4 animate-spin rounded-none bg-background"></div>`) combined with `flex items-center justify-center gap-3` on the button wrapper.
**Action:** Use this precise HTML and CSS structure when adding loading states to maintain design consistency and ensure elements are properly aligned within buttons.

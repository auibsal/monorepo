## 2024-05-14 - Missing Accessible Feedback and Focus States on Custom Form Controls
**Learning:** The custom brutalist UI components (like login forms and buttons) were missing explicit `role="alert"` for dynamic error messages, meaning screen readers weren't announcing login failures. Additionally, custom background/shadow states on elements like buttons and Links were obscuring or missing default browser focus rings (`focus-visible`), hindering keyboard navigation accessibility.
**Action:** Always ensure dynamic feedback elements receive `role="alert"` or `role="status"` per instructions. When overriding native button/link styles with custom background colors or shadows (especially in brutalist design patterns), always explicitly add `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:ring-offset-background` to guarantee keyboard accessibility.

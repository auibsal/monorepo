## 2026-05-15 - Adding accessibility attributes to generic format tools
**Learning:** Adding aria-labels to generic component symbols like 'B' for Bold or 'I' for italics greatly improves accessibility for users employing screen readers, as well as making these generic buttons focusable via 'focus-visible' properties. 'aria-pressed' can also be dynamically provided for screen readers to verify whether a given formatting option is currently active or not. Using 'type="button"' inside elements that contain forms stops default form submission when user clicks one of the formatting buttons.
**Action:** Always add 'aria-labels', 'focus-visible' outlines, and dynamically generated 'aria-pressed' properties for format buttons inside Rich Text Editors. Add 'type="button"' to formatting buttons to prevent unintended actions like form submissions on standard mouse-clicks.

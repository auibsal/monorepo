## 2026-07-06 - Next.js Link and a tag focus states
**Learning:** Next.js `Link` elements and anchor (`a`) tags in layout components often lack default focus states, causing keyboard navigation accessibility issues.
**Action:** Always add explicit keyboard focus styles (e.g., `focus-visible:ring-2 focus-visible:ring-offset-2`) to Next.js `Link` elements and anchor (`a`) tags in layout components to maintain consistent keyboard navigation accessibility.

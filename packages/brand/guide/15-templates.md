# Templates

Every template the Society uses, in one place, each made once in
`packages/brand` and drawn here from the same code the site prints and
sends with (decisions.md, one design per thing). Open one to see it in
both languages.

| Template | What it is for | Where it is used |
| --- | --- | --- |
| [Form](?path=/story/components-brand--form-page-story) | Every signed form: one page, one signature | `/forms/<number>`; printed from the browser |
| [Printed form](?path=/story/components-brand--printed-form) | The same form on paper, for a signature by hand | Printed from the form's page |
| [Letter](?path=/story/components-brand--letter-story) ([Arabic](?path=/story/components-brand--letter-arabic)) | The one letter template: service letters (F-05) and the Society's letters | Record → Letters; printed from the browser |
| [Certificate](?path=/story/components-brand--certificate-story) ([Arabic](?path=/story/components-brand--certificate-arabic)) | Two kinds only: finishing Qalam and the Mutanabbi Prize, each with two signatures | Record → Certificates; checked at `/verify` |
| [Membership card](?path=/story/components-brand--membership-card-story) ([Arabic](?path=/story/components-brand--membership-card-arabic)) | Everyone with an account; the live code for the door | Today; Google Wallet |
| [Document](?path=/story/components-brand--document) | The Library's documents, with code, keeper and status | `/library` |
| [Email](?path=/story/emails-platform--rsvp-confirmed) | Every email the platform sends, one template, both languages; send yourself a test from each | The outbox; Resend |
| [Sign-in emails](?path=/story/emails-sign-in--confirmation) | Supabase's own emails, in the Society's template | Sign-up, password, two-step |
| [Email signature](?path=/story/components-brand--email-signature-story) | Each seat's signature in Gmail | Every role mailbox |
| [With the support of](?path=/story/components-brand--with-the-support-of-story) and [Supported by](?path=/story/components-brand--supported-by-story) | AUIB's offices on /partners; a sponsor in kind on its event | `/partners`; an event's page |
| [Social posts](?path=/story/social-templates--posts-english) ([Arabic](?path=/story/social-templates--posts-arabic)) | Instagram posts and carousels | Media; the content calendar in Notion |
| [Stories](?path=/story/social-templates--story-english) ([Arabic](?path=/story/social-templates--story-arabic)) and [highlights](?path=/story/social-templates--highlights) | Instagram stories and highlight covers | Media |
| [Posters and printables](?path=/story/print--printables) | Posters, stickers and the sizes they print at | Events; the Typewriter Tour |
| [Hudhud](?path=/story/components-hudhud--hudhud) | The bot's look and its stickers | Telegram |

A new kind of thing gets its template here first; a page never draws its
own.

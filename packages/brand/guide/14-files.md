# Files and templates

Everything lives here, in the Society's design system in the Diwan, built from `packages/brand` in the platform's repository. Every file has its download in Logos, Social and Print.

| File | What it is |
| --- | --- |
| `sal-lockup-horizontal(-reversed).svg` | Symbol + English; everything in English |
| `sal-lockup-horizontal-ar(-reversed).svg` | Arabic + symbol; everything in Arabic |
| `sal-lockup-bilingual(-reversed).svg` | English \| symbol \| Arabic; signage, banners, merchandise |
| `sal-lockup-stacked(-reversed).svg` | Symbol over English; stickers, merchandise |
| `sal-symbol.svg` · `sal-symbol-white.svg` | The Bookmark alone |
| `sal-wordmark-en` / `-ar` (`-reversed`)`.svg` | The wordmarks; alone on the last slide of a carousel |
| `sal-avatar.svg` · `sal-avatar-ink.svg` | The Bookmark in white on crimson (Instagram, the members' group) or on ink (the Diwan group) |
| `hudhud*.svg` / `.png` · stickers | Hudhud, his avatar and twelve stickers |
| `UbuntuArabic-Regular` / `-Bold.woff2` | The Arabic typeface, shipped with the system |
| `icon-*.svg` | The icon set, one per meaning |
| `tokens.json` · `bundle.css` | Colors, type, space and the components: cover, footer, form, post, carousel, story, highlights, icons |

**Fonts.** Ubuntu, Ubuntu Mono and Literata are free from Google Fonts. Ubuntu Arabic is not on Google Fonts: install it from the design system ([Regular](brand-kit/fonts/UbuntuArabic-Regular.ttf), [Bold](brand-kit/fonts/UbuntuArabic-Bold.ttf)). Install them before editing any template. In Canva, upload the logo SVGs and Ubuntu Arabic to the Brand Kit with the six colors.

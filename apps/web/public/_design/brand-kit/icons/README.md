The Society's icon set: Lucide (ISC license, lucide.dev), redrawn for the brand at a 1.5 px line on a 24 px grid, with square ends and square corners. Each file uses `currentColor`, so paste the SVG inline and it takes the color of the text beside it. As an `<img>` it draws in black: use it that way only in tools that cannot inline SVG, and recolor it there to `ink` or white.

**Use:** on its own when the meaning is plain, with a word when it could be misread; at the text's size (1.15 em), in the text's color. A standalone icon on a screen carries an `aria-label`. See the Iconography section of the README and `components/Icons`.
